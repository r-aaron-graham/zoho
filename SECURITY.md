# Security reporting and deployment scope

Use GitHub private vulnerability reporting when enabled. Otherwise request a private reporting channel through an issue without publishing sensitive records or exploit details.

Contact exports may contain personal information. Keep production exports outside this repository and restrict access to input and output files. The CLI validates the full batch before replacing output, using a temporary file in the output directory. File replacement follows the operating system's atomic rename behavior.

The example performs local conversion. Live authentication, API permissions, transport, quotas, and retry reconciliation require integration-specific verification.
